### Fixed

- **Free space is checked on the right disk on Linux, macOS and in Docker.** Packwright measured the system disk instead of the disk a folder is really on. In the Docker and Unraid version that was the container's own disk, so merging a large package into your games share was refused with terabytes free. On Linux and macOS a game on another disk (`/media/...`, `/mnt/...`, `/Volumes/...`) was measured against the system disk. This affected:
  - merging packages downloaded in parts, and merging in place
  - the free-space check before converting or building
  - the per-drive free space on the **Health** page
  - moving library items between disks
- Merging still writes the new package straight into its output folder.
- Windows behaves as before.

If you already have Packwright 1.4.1, open **About** and choose **Check for updates**. On Unraid, use **Check for Updates** on the Docker page.
