### What is new

- **Choose where temporary work files go.** Converting an image, or editing the details of an FFPFSC image or a package, unpacks the whole game first. Those files no longer have to fill your system drive: pick a folder under **Settings > Output and naming > Temporary folder**, or keep them next to the output. On the command line, `--temp <folder>` sets it for one run. If the chosen folder cannot be used, the job stops and says so instead of writing to the system drive. Thanks to kopihitam.
- **Arch Linux package and AppImage.** Each release now also has `Packwright-v<version>-linux-x64.pkg.tar.zst` for Arch, Manjaro and EndeavourOS (`sudo pacman -U ./<file>`), and a `Packwright-v<version>-linux-x64.AppImage` that runs on any 64-bit distribution with nothing to install. Update checks offer the AppImage when you run one, and the Arch package on Arch-based systems.
- The library scan skips Packwright's own work folders (`.Packwright-…`), so a half-built copy next to an output is not listed as a title.

If you already have Packwright 1.1.0, open **About** and choose **Check for updates**.
