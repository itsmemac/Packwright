### What is new

- **Merge packages downloaded in parts.** Large PlayStation downloads come as `<name>_0.pkg`, `<name>_1.pkg`, ... and `<name>_sc.pkg`. Choose any part (or the folder) on the **Tools** page and pick **Merge parts**, or run `packwright merge <part or folder>`. The parts are joined in number order with the `_sc` part last, where the package header says its container starts.
  - Before anything is written, Packwright checks for a missing part, one that did not finish downloading, one from another download, or a missing `_sc` part, and names it. The merged file is checked again at the end. No keys are needed.
  - **New file** (the default) keeps the parts. **Merge in place** adds each part onto part 0 and deletes it once it is safely written, so it needs only about one part of free space. If it is interrupted, run it again and it carries on where it stopped.
  - The library lists a package in parts once, as "PKG in N parts", with a reminder to merge it.
- **Verify checks retail and patch packages.** It confirms the metadata container is where the header says and that its seal, contents, header and image superblock digests match. A package merged with `_sc` in the wrong place, which does not install, is now reported.

If you already have Packwright 1.2.0, open **About** and choose **Check for updates**.
