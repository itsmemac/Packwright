### What is new

- **Packwright now has its own package engine.** It reads, verifies, extracts and builds PS5 packages with no third-party engine and no bundled binary, and ships no keys. Builds stream the files into the package, so they need no workspace folder, only room for the package.
- **Kraken compression** for package builds (Auto, Kraken or uncompressed), with the size of the original packages.
- **Editing a package's details and icon takes seconds.** Only the metadata is rewritten; the rest of the package is copied. Changing the Content ID still rebuilds it in full.
- **Extracting a package also writes its `sce_sys` entries**, so the result is a complete folder that can be built into a package again.
- **Missing icon textures** (`icon0.dds`, `pic*.dds`) are generated, and a replaced icon updates its texture.
- **Missing `keystone` or `right.sprx`:** Packwright never makes one. The package is built without it and the log says which files are not present.
- **Compatibility keys (optional):** import public values from a file of your own under Settings; see `docs/KEYS.md`. Nothing is shipped.
- **Build options:** play-go chunks, DRM type, SDK version, reproducible output. The builder choice and the workspace, fake-sign and right.sprx options are gone with the old engines.
- **Patch packages** are described from their headers.
- A note on the build options says packages are verified on a PC but not tested on a console.

If you already have Packwright 1.0.1, open **About** and choose **Check for updates**.
