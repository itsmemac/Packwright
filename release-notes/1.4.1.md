### Fixed

- **Right-click menus work in the Docker and Unraid version.** Right-clicking a game card, a list row or a column header did nothing in the browser. The image was missing an X library (`libXi`), and without it the right-button release never reached the app. Update the container to get the fix; your settings and library stay as they are.
- The README now points Unraid users to the template repository, `https://github.com/itsmemac/unraid-template`. The old template link keeps working.
- The desktop app is unchanged.

If you already have Packwright 1.4.0, open **About** and choose **Check for updates**. On Unraid, use **Check for Updates** on the Docker page.
