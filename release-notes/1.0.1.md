### What is new

- **Send to console is much more reliable.** The progress bar and the sizes (done, left, total) now work. If the connection drops, for example when a phone goes to sleep, Packwright waits, reconnects and carries on by itself. FTP servers that need a user name and password (a phone or PC running an FTP app) are supported in **Settings, Manage consoles**.
- **Clear error messages.** Problems on the Tasks page are now written in plain words and say what to check. The technical details are saved in the log.
- **Verify tells you the result.** A finished check says "Verified: no problems found" with what was checked and how long it took. A failed check says in plain words what is wrong and what to do. Verifying an image now also shows real progress.
- **Right-click a game for Convert / Build, Extract or Verify.** Each one opens Tools with the game and the action already chosen.
- **Tasks show how much is done.** Every task that knows its size shows the amount done, left and total.
- **Tools:** a built-in ZArchive preset. Presets now only appear for Convert / Build, so they no longer switch you away from Verify or Extract.
- **A clearer task counter** in the sidebar, including the collapsed sidebar.
- A package that is incomplete or damaged now says so, instead of suggesting a passcode problem.

If you already have Packwright 1.0.0, open **About** and choose **Check for updates**.
