### What is new

- **Run Packwright on your NAS and use it from a browser.** A Docker image, `ghcr.io/itsmemac/packwright`, now comes with every release, along with an Unraid template. It is the same Linux app, shown in the browser, so it works on your games at the server's own disk speed instead of over a network share or a VM's shared folder.
  - Open `https://<server>:5800` and sign in. You set the username and password when you install it.
  - Mount your games at `/games`, which becomes the library on first start. Work files go to `/temp`, and settings to `/config`.
  - Files are written as Unraid's `nobody:users` (99:100) by default.
  - On Unraid, add the container with the template `https://raw.githubusercontent.com/itsmemac/Packwright/main/unraid/packwright.xml`. The README section "Unraid and Docker" has the details and a `docker run` example.
- The desktop app is unchanged.

If you already have Packwright 1.3.0, open **About** and choose **Check for updates**.
